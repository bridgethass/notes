# Cloud Native

**Summary**: Cloud-native data formats, tools, and communities, especially for geospatial data.
**Last updated**: 2026-11-18

- [STAC: SpatioTemporal Asset Catalogs](https://stacspec.org/en): STAC is a specification for describing and cataloging geospatial data about the Earth, such as satellite imagery ([[Remote_Sensing]]), so users can search and access any dataset in the same way. *Keywords: STAC, specification, metadata, data catalog, satellite imagery, geospatial*
