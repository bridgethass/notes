# Web Design

**Summary**: Designing and building websites, including layout, typography, color, performance, and AI-assisted site building.
**Last updated**: 2026-11-18

---

- [Portfolio Website Template (Spatial Thoughts)](https://github.com/spatialthoughts/portfolio-website-template/): A MkDocs Material template for [[Geospatial]] professionals to build a portfolio site on GitHub Pages, with no Git or coding skills needed. It goes with a Spatial Thoughts workshop ([[Training]]). *Keywords: portfolio, website template, MkDocs, GitHub Pages, GIS career*
- [Evan Applegate (@youwillmakemaps) on X: Building a website with Claude Code](https://x.com/youwillmakemaps/status/2115984033201148376): A 9-step guide to building fast, attractive sites with [[Agentic_Coding]]: write the copy, collect design inspiration, limit yourself to 2 colors and 2 fonts, deploy via CLI (GitHub, Cloudflare, Resend), then tune Lighthouse scores and SEO. The post recommends [rybitten.space](https://rybitten.space/) for picking colors and [Scrawl](https://scrawl.kitlangton.com/) for annotating screenshots to send to the model. *Keywords: web design, Claude Code, website, Cloudflare, Lighthouse, typography*
